# Design sources

Sources and provenance for generated assets. Not part of the Hugo build — these
are regenerated by hand when the branding changes.

## Webfonts → `static/fonts/`

| Family | Declared weights | Subsets | License |
|--------|------------------|---------|---------|
| [Merriweather](https://fonts.google.com/specimen/Merriweather) | 400–700 (variable), 400 italic | latin, latin-ext | [SIL Open Font License 1.1](https://openfontlicense.org/) |
| [Raleway](https://fonts.google.com/specimen/Raleway) | 500–700 (variable) | latin, latin-ext | [SIL Open Font License 1.1](https://openfontlicense.org/) |

The woff2 files are the per-subset builds Google Fonts serves, saved locally so
pages make no third-party request. Google ships both families as variable fonts
and returns the *same* file for every requested weight, so one file per
style/subset is kept and `@font-face` declares a weight range. Total shipped is
about 330 KB; an English page downloads only the `latin` files it uses (roughly
140 KB for body + headings, plus 50 KB if the page has italics).

`@font-face` rules live in `assets/css/extended/fonts.css`; the two above-the-fold
faces are preloaded in `layouts/partials/extend_head.html`.

To regenerate or add a weight: fetch the Google Fonts CSS with a modern browser
user agent, keep the `latin` / `latin-ext` blocks, download each `url(...)`, and
rewrite the `src` to `/fonts/<file>.woff2`. Dedupe by checksum before committing.

```bash
curl -fsSL -A "Mozilla/5.0 (Macintosh) AppleWebKit/537.36 Chrome/130.0 Safari/537.36" \
  "https://fonts.googleapis.com/css2?family=Merriweather:ital,wght@0,400;0,700;1,400&family=Raleway:wght@500;600;700&display=swap"
```

## `og-default.svg` → `static/images/og-default.jpg`

The social preview card (Open Graph / Twitter) referenced by `params.images`
in `hugo.toml`. Social platforms do not render SVG, so it ships as a 1200×630 PNG.

The SVG canvas is deliberately **1200×1200 square** with the visible card
occupying `y = 285..915`. Rendering square keeps `qlmanage` from rescaling the
artwork, then the centre band is cropped out. To regenerate on macOS:

```bash
qlmanage -t -s 1200 -o /tmp design/og-default.svg
sips -c 630 1200 /tmp/og-default.svg.png --out /tmp/og-card.png
sips -s format jpeg -s formatOptions 88 /tmp/og-card.png --out static/images/og-default.jpg
```

JPEG keeps the gradient under ~55 KB; the same card as PNG is ~650 KB.

Verify the result is exactly `1200 x 630`:

```bash
file static/images/og-default.jpg
```

## `static/favicon.svg` → raster icons

PaperMod always emits three `<link rel="icon">` tags and defaults the two raster
slots to `favicon-16x16.png` / `favicon-32x32.png`, so those files must exist or
they 404 on every page. Regenerate all of them from the SVG:

```bash
qlmanage -t -s 360 -o /tmp static/favicon.svg
for s in 16 32; do
  sips -s format png --resampleHeightWidth $s $s /tmp/favicon.svg.png \
    --out static/favicon-$s\x$s.png
done
sips -s format png --resampleHeightWidth 180 180 /tmp/favicon.svg.png \
  --out static/apple-touch-icon.png
```

Edit `static/favicon.svg` only; treat the PNGs as build products.

## `static/safari-pinned-tab.svg`

Safari's pinned-tab icon is a *mask*: Safari recolours it from the alpha channel
alone, so the filled card in `favicon.svg` would render as a solid rounded
square. This file is a separate monochrome (black on transparent) version of the
same "LH" mark. Edit it by hand alongside `favicon.svg`; it is not generated.

## `covers/*.svg` → `static/images/covers/*.png`

Article cover images, drawn as SVG at 1600×900 and rendered to PNG with headless
Chrome so system fonts (Georgia, Helvetica Neue) render identically every time:

```bash
node -e '
const p=require("puppeteer-core");(async()=>{const b=await p.launch({executablePath:"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",headless:true});
const g=await b.newPage();await g.setViewport({width:1600,height:900});await g.goto("file://"+process.argv[1]);await g.screenshot({path:process.argv[2],clip:{x:0,y:0,width:1600,height:900}});await b.close();})()' \
  "$PWD/design/covers/<slug>.svg" "$PWD/static/images/covers/<slug>.png"
```

`puppeteer-core` is installed in a scratch folder, not in this repo. The PNG is
referenced from the post's `cover.image` front matter (PaperMod shows it above the
post and uses it as the social-share image) and copied to `linkedin/assets/` for
upload as the LinkedIn article cover.
